# Triage

Triage holds unresolved or deferred candidates until promotion. It is intake,
not execution.

## Rules

- A triage note names the candidate, its constraints, open questions, source
  references, promotion condition, and owner or next check when known.
- Triage is non-authoritative: nothing here authorizes implementation. Work
  starts only when a candidate is promoted into an executable Northstar task
  (`gNN.NNN`) under `docs/roadmaps/`.
- Roadmaps contain only promoted executable tasks. Never execute a triage
  note directly, and never treat migration into triage as approval.
- Promotion requires operator direction (or the standing trigger recorded in
  the note) plus an owning task with unambiguous scope.
